\# Task 3: Defenses Against Gradient Reconstruction Attacks



\## Overview



Task 3 implements defenses against gradient reconstruction attacks in

Federated Learning (FL).



The defenses are applied to the single-sample client gradients generated

during Task 1.



The two defenses implemented in this task are:



1\. Gradient Clipping

2\. Differential Privacy using Gaussian Noise



\---



\## Input



The defense algorithms use the client gradient files generated by Task 1:



```text

task1\_fl\_setup/updates/

├── client1\_gradient.pt

├── client2\_gradient.pt

├── client3\_gradient.pt

└── client4\_gradient.pt

```



Each `.pt` file contains a list of gradient tensors corresponding to the

model parameters for one client.



The original gradient files are not modified by Task 3.



\---



\# 1. Gradient Clipping



Gradient clipping limits the global L2 norm of the complete client

gradient.



If the gradient norm exceeds the selected clipping threshold, all

gradient tensors are scaled by the same factor so that the resulting

global norm is approximately equal to the clipping threshold.



\### Clip Values Tested



The following clipping thresholds are evaluated:



```text

C = 1.0

C = 0.5

C = 0.1

```



\### Implementation



The implementation is provided in:



```text

gradient\_clipping.py

```



The script performs the following steps:



1\. Loads the original client gradient.

2\. Calculates the global L2 norm across all gradient tensors.

3\. Calculates the clipping scale factor.

4\. Applies the same scale factor to all gradient tensors.

5\. Saves the protected gradient for each clipping threshold.



\### Output



The protected gradients are saved in:



```text

protected\_updates/

```



Example output files:



```text

client1\_gradient\_clip\_1.0.pt

client1\_gradient\_clip\_0.5.pt

client1\_gradient\_clip\_0.1.pt

```



The same files are generated for clients 2, 3, and 4.



A total of 12 clipping outputs are generated:



```text

4 clients × 3 clipping thresholds = 12 files

```



\---



\# 2. Differential Privacy



Differential privacy is implemented experimentally by first clipping the

gradient and then adding Gaussian noise.



For the DP experiments, the clipping threshold is fixed at:



```text

C = 1.0

```



Gaussian noise is then added independently to every gradient tensor.



\### Noise Levels Tested



The following Gaussian noise levels are evaluated:



```text

σ = 0

σ = 0.01

σ = 0.05

σ = 0.1

σ = 0.5

```



\### Processing Pipeline



```text

Original Gradient

&#x20;      |

&#x20;      v

Gradient Clipping (C = 1.0)

&#x20;      |

&#x20;      v

Gaussian Noise Addition

&#x20;      |

&#x20;      v

Protected Gradient

```



\### Implementation



The implementation is provided in:



```text

differential\_privacy.py

```



The script performs the following steps:



1\. Loads the original client gradient.

2\. Clips the gradient using `C = 1.0`.

3\. Generates Gaussian noise for each gradient tensor.

4\. Adds the noise to the clipped gradient.

5\. Saves the resulting protected gradient.



\### Output



The protected gradients are saved in:



```text

protected\_updates/

```



Example output files:



```text

client1\_gradient\_dp\_0.0.pt

client1\_gradient\_dp\_0.01.pt

client1\_gradient\_dp\_0.05.pt

client1\_gradient\_dp\_0.1.pt

client1\_gradient\_dp\_0.5.pt

```



The same files are generated for clients 2, 3, and 4.



A total of 20 DP outputs are generated:



```text

4 clients × 5 noise levels = 20 files

```



Therefore, Task 3 generates:



```text

12 clipping outputs + 20 DP outputs = 32 protected gradient files

```

\# 4. Differential Privacy Results



All DP experiments use:



```text

C = 1.0

```



The measured protected gradient norms are:



| Client | Original | σ = 0 | σ = 0.01 | σ = 0.05 | σ = 0.1 | σ = 0.5 |

|--------|----------|--------|-----------|-----------|----------|----------|

| Client 1 | 2.0174 | 1.0000 | 1.5356 | 5.8781 | 11.6533 | 56.9328 |

| Client 2 | 2.1358 | 1.0000 | 1.5426 | 5.9531 | 11.5734 | 58.1479 |

| Client 3 | 2.1432 | 1.0000 | 1.5464 | 5.8697 | 11.6548 | 57.8198 |

| Client 4 | 2.1801 | 1.0000 | 1.5467 | 5.8252 | 11.5742 | 58.1292 |



The protected norm increases as the noise level increases because

Gaussian noise is added to every gradient element.



However, gradient norm alone does not measure the effectiveness of the

privacy defense.



The actual effectiveness of the defenses should be evaluated using the

gradient reconstruction attack.



\---



\# 5. Reconstruction Attack Evaluation



The protected gradients generated by Task 3 are intended to be used as

inputs to the gradient reconstruction attack in the next stage of the

project.



The protected gradients are located in:



```text

protected\_updates/

```



The following outputs can be evaluated:



```text

client\*\_gradient\_clip\_\*.pt

client\*\_gradient\_dp\_\*.pt

```



The reconstruction results should be compared with the results obtained

using the original unprotected gradients:



```text

task1\_fl\_setup/updates/client\*\_gradient.pt

```



Recommended evaluation metrics include:



\- Reconstruction MSE

\- PSNR

\- SSIM

\- Attack success rate

\- Label recovery accuracy

\- Model accuracy



The expected objective is to reduce the quality and success of gradient

reconstruction while maintaining acceptable model utility.

\# 9. Differential Privacy Note



The Gaussian noise implementation in this task uses experimentally

specified noise levels:



```text

σ = 0, 0.01, 0.05, 0.1, 0.5

```



These values are used to study the effect of noise on gradient

reconstruction.



This implementation does not claim formal differential privacy

guarantees in terms of epsilon (ε) and delta (δ).



Formal differential privacy guarantees would require appropriate privacy

accounting together with the assumptions of the federated learning

protocol.



Therefore, the effectiveness of the defense should be evaluated using

the reconstruction attack metrics rather than protected gradient norm

alone.
